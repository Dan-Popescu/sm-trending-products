# T06 — Rank attention with inspectable reasons

**Status:** Software implemented; acceptance evidence is mapped in the [coverage record](../../implementation/coverage.md). Not published to GitHub.

## What to build

Let an operator compare attention around reviewed products, inspect why they rank, and retain an alert snapshot that later evidence cannot rewrite.

## Acceptance criteria

- [ ] Controlled timelines produce interval-adjusted growth and acceleration with age/cohort context and measured observation intervals.
- [ ] Creator/video spread, concentration, and likely creative duplication distinguish one viral post from broader product diffusion.
- [ ] Counter resets, corrections, stale evidence, insufficient sample size, and unknown fields are visible rather than interpreted as ordinary zeros.
- [ ] The private view reads a published result version and traces each feature to eligible observations and identity decisions.
- [ ] A versioned threshold creates a frozen alert with evidence, reasons, scope, cutoff, and cooldown behavior.
- [ ] Synthetic test alerts are isolated from the live review queue and all four assessment dimensions remain separately represented.
